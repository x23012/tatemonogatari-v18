# たてものがたり アプリ開発キット

ボードゲーム「たてものがたり」で集めた文化財カードを、実際に巡るルートに変えるスマホアプリを作るための資料一式です。
別の場所（別のAI・開発ツール・チーム）で開発するときは、このフォルダをまるごと渡してください。

## 中身
| ファイル | 内容 |
| --- | --- |
| APP_SPEC.md | アプリの仕様（目的・画面・機能・データの使い方） |
| DESIGN.md | 色・文字・カードのデザインの決まり |
| RULES.md | ゲームのルール（アプリ内の遊び方ページに使える） |
| data/cards.json | 文化財カード47枚のデータ（アプリはこれを読み込む） |
| data/cards.csv | 同じデータの表形式（確認・編集用） |
| photos/ | 47枚の写真（ファイル名＝カードID） |
| tools/make_qr.py | カード用QRコードを作るスクリプト（公開URLが決まったら使う） |
| reference/ | カード見本と、前に作った試作アプリの画面 |

## AIに渡すときの指示の例
> このフォルダの APP_SPEC.md と DESIGN.md に従って、スマホで動くWebアプリを作ってください。
> データは data/cards.json、写真は photos/ を使ってください。
> まず「カードを選ぶ → ルート確認 → Googleマップで案内」の流れが動くところまで作ってください。

## 注意
- 前の試作（reference/前の試作_*.png）は、起承転結の4枚を選ぶ旧ルール時代のものです。画面の雰囲気の参考にとどめてください。
- 位置情報（lat / lng）はまだ入っていません。今は `map_query`（正式名称＋市区町村）でGoogleマップ検索する方式です。
- 18枚の写真に「解像度が低い」などの注意があります（`photo_note`）。
